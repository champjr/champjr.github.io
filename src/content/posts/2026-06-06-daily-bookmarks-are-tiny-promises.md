---
title: "Bookmarks Are Tiny Promises to Your Future Self"
pubDate: 2026-06-06
description: "Most bookmarks are not archives, they are little acts of optimism about the person we think we will be later."
tags: [daily, bookmarks, internet, productivity, writing]
---

A bookmark looks like a storage action, but it is usually a hope action.

When I save a link, I am rarely saying, “I need durable access to this resource in a well-maintained personal knowledge system.” I am saying something much simpler and much more human: “this seems important, and I would like to become the kind of person who comes back for it.”

That is why bookmark lists get weird so quickly. They start out looking like organization and end up feeling like emotional archaeology. A few entries are practical. Most are tiny frozen aspirations. Read this essay later. Learn this library later. Fix your note-taking setup later. Become more informed about urban design, typography, fermentation, local-first software, browser internals, and maybe also sailing, somehow, later.

The modern web gives us an absurd number of ways to postpone attention. We can bookmark things in the browser, save them to read-later apps, throw them into notes, send them to ourselves in chat, star them in GitHub, pin them in Slack, or leave forty-seven tabs open as a monument to ambition. This is not a criticism, exactly. It is just the shape of life online when discovery is cheap and attention is expensive.

I think the mistake is treating every saved link as a failure to be corrected. Sometimes people talk about unread bookmarks the way they talk about an inbox with 30,000 messages, as if the correct response is shame plus a weekend project. I am not convinced. A chaotic bookmark list is often evidence of curiosity, not moral weakness. The problem is not that we save too much. The problem is that we pretend every saved thing belongs in the same category.

Some links are tools. Some are references. Some are rabbit holes. Some are souvenirs.

That last category matters more than software people usually admit. A lot of saved links are not there because we will use them. They are there because we liked stumbling across them. An old blog post with a beautifully cranky argument. A handmade website from 2007 that still looks like it was assembled with love and mild CSS resentment. A project page for something impractical and delightful. Those links are not tasks. They are proof that the web still occasionally feels like wandering.

This is one reason I still like the idea of personal link gardens, small collections of links kept with a little annotation or context. They make room for taste, which ordinary bookmarking systems flatten into raw accumulation. A list that says “here are three essays that changed how I think about software maintenance” is more alive than a pile of 900 anonymous saves. You do not need a grand knowledge-management framework for this. A Markdown file works. So does a page on your site. So does a note called “stuff worth re-finding.”

If you want a good example of this spirit, I still enjoy browsing [blogrolls and hand-built web pages collected by Marginalia Search](https://search.marginalia.nu/). It reminds me that the internet is better when it feels less like a feed and more like a trail.

My current theory is that bookmarks work better when you stop expecting one system to do four jobs.

A useful bookmark needs a destination. Put reference material where reference material lives. Save code things with code things. Keep travel ideas with travel ideas.

An aspirational bookmark needs a review habit. If you really do want to read those long essays, a weekly “what do I actually want from this pile?” pass works better than perpetual guilt.

A sentimental bookmark needs permission to just exist. You are allowed to keep a link because it made you grin.

And a dead bookmark, honestly, deserves a dignified death. Some links are saved versions of a person you are no longer trying to become. That abandoned course on mastering some niche framework in your spare time may not be calling you anymore. Let it go. Your bookmark list does not need to preserve every alternate timeline.

The funny part is that good bookmarking is probably less about better capture and more about better honesty. Why am I saving this? Because I need it for work? Because I want to read it tonight? Because it represents a life admin chore I am avoiding? Because I just want to remember that something cool exists?

The answer changes what should happen next.

I do not think we need a more powerful universal bookmark engine nearly as much as we need interfaces that admit human motives are messy. Give me a bookmark button with moods. Save for reference. Save for this weekend. Save because this is delightful. Save because I am definitely not going to read this, but I want the option to pretend.

That last one would get a lot of use.

Until then, I am trying to be kinder to my own pile of saved links. It is not a perfect system. It is a map of passing interests, unfinished intentions, and occasional genuine gems. That feels less like failure and more like evidence that the web is still producing more interesting things than any one person can hold in their head.

Which, in fairness, is a pretty good problem to have.
